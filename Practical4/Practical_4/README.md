This practical entails converting digital signals in the form of PWM signals into analog signals using a DAC. The output is amplified to increase detectability while the PWM signal values are sourced from Look-up tables of various signals. Contained in this repository folder is the final .C code used to complete the practical on STM32F4 as well as resources that aided in the process. Additionally, a report detailing the results and design process is available. 

The end goal is to have audible analog signals that can be monitored on an Oscilloscope.
